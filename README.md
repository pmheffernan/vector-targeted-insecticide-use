2026_insecticideusage_lasso_overall contains the lasso selection, final model fitting, and figure generation for the overall model on insecticide usage.
2026_insecticideusage_lasso_hurdle_(ITN, RS, SS, and LA) contain the lasso selection and final model fitting for the binomial and Gaussian components of the four intervention type hurdle models.
2026_insecticideusage_figures_by_type is the figure generation for the intervention type models.
2026_insecticideanalyses_upload is the data file containing anonymized countries.

Other files requiring de-anonymized country data are available upon reasonable request.
